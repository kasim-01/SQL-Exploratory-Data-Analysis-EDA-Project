📊 **SQL Exploratory Data Analysis (EDA) Project**

I’m excited to share my latest **SQL EDA project**, where I explored and analyzed a dataset using SQL to uncover meaningful patterns, trends, and business insights.

🔍 **What I worked on:**
• Data exploration and understanding
• Data cleaning and validation
• Aggregations using `SUM()`, `AVG()`, `COUNT()`, `MIN()`, and `MAX()`
• Filtering with `WHERE` and `HAVING`
• Data analysis using `GROUP BY` and `ORDER BY`
• Joining multiple tables using `JOIN`
• Subqueries and CTEs
• Window functions such as `RANK()`, `DENSE_RANK()`, `ROW_NUMBER()`, and `LAG()`
• Time-based analysis
• Identifying trends, patterns, and key insights

🛠️ **Tools & Technologies**

* SQL
* Microsoft SQL Server
* SSMS
* GitHub

🎯 **Project Goal**

The main goal of this project was to strengthen my SQL skills and practice solving real-world data analysis problems using structured data.

💡 **Key Learning**

This project helped me improve my understanding of how SQL can be used not just to retrieve data, but also to **analyze data, identify patterns, and generate useful business insights**.

I’m continuing to build my skills in **SQL, Excel, Power BI, and Python** as I work toward a career in **Data Analytics**.
